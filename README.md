# JEETrigo11

Class 11 / JEE trigonometry cheat sheet: formulae with graphs for amplitude, phase, products, slope, and signed area.

## Run locally

```bash
cd ~/Projects/jee-trigo-cheatsheet
npm install
npm run dev
```

Open the URL Vite prints, usually http://localhost:5173/

Use **Print / PDF** in the header for a paper copy.

## Sections

- Foundations — unit circle, ASTC, domain/range, allied angles
- Graphs & phase — six standard graphs, period traps, `a sin(bx+c)+d`
- Identities — products, sums, resultant `R sin(x+α)`
- Equations — general solutions as graph intersections
- Differentiation — derivative as slope of the tangent
- Integration — definite integrals as signed area
- JEE bank — compound, multiple, half-angle, product ↔ sum
